# 边录边译隐私政策增补设计

## 目标

在 Starfire AI 中英文隐私政策中明确披露“边录边译”功能涉及的数据、权限、本地处理方式和保存删除规则，不改变应用功能或现有隐私同意流程。

## 披露口径

- 用户主动启动边录边译后，应用才使用摄像头和麦克风采集本次音视频。
- 语音识别和翻译在设备本地完成，不主动上传至运营者服务器。
- 录制期间产生的音频片段、无声视频、转写和译文属于本地临时数据。
- 用户完成并选择生成后，相关内容按视频工程规则保存在应用沙盒；用户取消时，应用清理其管理的临时文件。
- 用户主动导出或分享后，副本由用户选择的目标位置或接收方继续处理。

## 修改位置

1. “信息处理”中的视频、字幕与翻译工程：加入边录边译采集的音视频、转写与译文。
2. “设备权限”：相机和麦克风说明加入边录边译的按需使用场景。
3. “信息保存与删除”：说明完成时按项目保存、取消时清理临时文件。
4. “数据传输”：明确边录边译识别与翻译主要在本地完成，不主动上传。
5. 英文部分同步提供含义一致的披露。

## 边界

- 不修改 Flutter 或 iOS 功能代码。
- 不新增权限，也不改变权限请求时机。
- 不声明所有系统行为绝对离线；Apple 系统资源下载、模型下载、友盟统计及用户主动分享仍沿用现有政策说明。

## 验证

- 检查中英文均包含边录边译、摄像头、麦克风、本地处理、保存与取消清理说明。
- 检查 HTML 结构可解析，现有政策链接和页面布局不变。
